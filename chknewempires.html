🔍 Card Checker

Test real de tarjetas contra checkout (Stripe / Shopify / otros). Luhn + HTTP + Provider detection + Token API.

🔗 Link de Producto

Pega el link directo. Si el servidor bloquea CORS, se usa un proxy automático (allorigins).

💳 Tarjetas

Formato: número (16-19 dígitos) | MM/YY o YY/MM | CVV (3-4). Soporta espacios como separador también.

🌐 Proxies

En navegador, los proxies se usan como CORS proxy wrapper (http://host:port/?url=). SOCKS requiere un bridge WS.
